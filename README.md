# Python-Spot-Painting

![Damien Hirst's Spot Painting](https://i.postimg.cc/fLtysxyD/GH5.webp)

A Python Turtle graphics project inspired by [Damien Hirst](https://en.wikipedia.org/wiki/Damien_Hirst)’s spot paintings.
This mini project combines programming fundamentals with generative art by creating colorful dot-grid paintings through code.

Interested to explore more?: [Click Here](https://www.myartbroker.com/artist-damien-hirst/articles/ultimate-guide-damien-hirst-facts)

Python Package used:
[colorgram](https://pypi.org/project/colorgram.py)
